# Biolab & Co. — Landing Page Institucional

## 📌 Sobre o Projeto

Este projeto consiste em uma landing page institucional desenvolvida para a empresa **Biolab & Co.**, voltada para o setor farmacêutico e biotecnológico.

A página foi criada com foco em:

- Apresentação institucional da empresa
- Divulgação de produtos e serviços
- Destaque para inovação e tecnologia
- Exibição de depoimentos profissionais
- Canal de contato com usuários
- Interface moderna e responsiva

O projeto utiliza apenas tecnologias front-end, sendo desenvolvido em HTML e CSS.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts
- Responsividade com CSS
- Estrutura semântica
